# AGENTS.md

Project-wide instructions for AI agents working in this repository.

## Language

- Write in English at B1–B2 level.
- Use short, direct sentences with one main idea each.
- Prefer present tense, active voice, and simple verbs.
- Use "we" for shared explanations.
- Avoid contractions, except "let's".
- Define unfamiliar technical terms.
- Avoid filler, promotional language, and unnecessary jargon.

## Formatting

- Use consistent Markdown formatting.
- Use em dashes (—), not hyphens, for breaks in a sentence.
- Use commas in thousands, for example `1,000`.
- Put code identifiers in backticks.

## Accuracy

- Follow the assignment requirements.
- Verify factual claims and sources before including them.

## Git

- Never commit or push without explicit permission.
