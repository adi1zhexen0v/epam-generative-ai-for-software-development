# Generative AI Dictionary

- **Generative AI** is a type of artificial intelligence that creates new content, such as text, images, audio, video, and code.

- **Large Language Model (LLM)** is an AI model trained on large amounts of text to understand and generate language.

- **AI Model** is a system trained on data to perform tasks, such as generating text, recognizing patterns, or creating images.

- **Prompt** is an instruction or request given to an AI model to produce a result.

- **Context window** is the maximum amount of information an AI model can process at one time, usually measured in tokens.

- **AI Agent** is an AI system that can use tools and perform multiple steps to complete a task.

- **Model Context Protocol (MCP)** is an open standard that allows AI applications to connect to external tools and data sources.

- **Skill** is a set of instructions and resources that helps an AI agent complete a specific type of task.

- **Reasoning effort** is a setting that controls how much reasoning a supported AI model uses when solving a problem.

- **Multi-Agent system** is a system where several AI agents work together or perform different tasks to achieve a common goal.

- **Agent orchestration** is the process of managing how AI agents perform tasks, share information, and work together.

- **Context engineering** is the process of selecting and organizing the information an AI model needs to complete a task correctly.

- **Code review** is the process of checking source code for errors, security problems, readability, and consistency with project standards.

- **Test-Driven development (TDD)** is a software development approach where developers write tests before implementing the code, then improve the code while keeping the tests passing.

- **Acceptance criteria** are specific conditions that a feature or task must meet to be considered complete.

- **Text-to-Speech (TTS)** is a technology that converts written text into spoken audio using computer-generated voices.

- **Deepfake** is an image, audio recording, or video created or modified with AI to make a person appear to say or do something they did not actually say or do.
