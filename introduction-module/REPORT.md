# Practical Task of Introduction Module — Research on Generative AI applications

This practical task includes research on five Generative AI use cases, a dictionary of 17 technical terms, and an optional interactive relationship graph.

## Files

- **[`research.md`](https://github.com/adi1zhexen0v/epam-generative-ai-for-software-development/blob/main/introduction-module/research.md)** — five Generative AI use cases, including business value, technical challenges, weak points, and existing implementations.
- **[`dictionary.md`](https://github.com/adi1zhexen0v/epam-generative-ai-for-software-development/blob/main/introduction-module/dictionary.md)** — 17 terms related to Generative AI and AI-native software development.
- **[`graph.html`](https://github.com/adi1zhexen0v/epam-generative-ai-for-software-development/blob/main/introduction-module/graph.html)** — an interactive graph showing explicit and implicit connections between the terms and use cases.

## How I used Generative AI

I used **EPAM AI/Run CodeMie with Claude Sonnet 5.5** to help organize and format my Markdown files. The agent followed the language and writing rules from [`AGENTS.md`](https://github.com/adi1zhexen0v/epam-generative-ai-for-software-development/blob/main/AGENTS.md) to keep the text clear, consistent, and close to my writing style.

For the optional task, I used CodeMie to create an interactive HTML graph based on the code style of my previous projects. I used Gephi as a visual reference because I had worked with it during my master's studies. This experience helped me choose a graph-based approach to show the relationships between vocabulary terms and research topics. In the prompts, I included graph connections, and the next task included only reviewing the generated results and making adjustments to the outcome.
